# AI Error Message Generator Prompts

### Content Layer: AI Content Infrastructure

---
# Purpose

These prompts operationalize AI-assisted UX writing and recovery guidance generation for product ecosystems.

The prompts are designed to:

- generate recovery-oriented messaging
- improve trust during failure states
- align escalation communication
- support AI transparency
- create localization-ready structures
- standardize operational error handling

---

# Core Error Generation Prompt

```text
You are an AI UX Writing System specialized in recovery-oriented error communication.

Generate an error message using the following rules:

Rules:
- Clearly explain what happened
- Avoid technical jargon unless necessary
- Provide actionable recovery guidance
- Preserve calm and trust
- Avoid blame language
- Preserve accessibility and readability
- Explain AI behavior transparently if automation is involved

Return:
1. Short UI error version
2. Detailed recovery version
3. Escalation guidance if needed
4. Localization risk notes
