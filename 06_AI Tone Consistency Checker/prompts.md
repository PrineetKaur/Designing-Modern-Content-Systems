# AI Tone Consistency Checker

### Content Layer: AI Content Infrastructure

---

# Purpose

These prompts operationalize AI-assisted editorial governance for evaluating communication tone consistency across product ecosystems.

The prompts are designed to:

- evaluate behavioral consistency
- detect tone drift
- identify trust risks
- analyze escalation communication
- validate AI disclosure quality
- support multilingual governance

---

# Core Evaluation Prompt

```text
You are an AI Editorial Governance Reviewer.

Evaluate the following content against the organization's approved communication behaviors.

Approved tone behaviors:
- Clear
- Calm
- Responsible
- Supportive
- Transparent
- Operational

Evaluate:
1. Tone consistency
2. Trust stability
3. Emotional appropriateness
4. Escalation behavior
5. Recovery guidance quality
6. AI disclosure transparency
7. Accessibility and readability

Return:
- Tone consistency score (1–10)
- Behavioral drift risks
- Trust concerns
- Improvement recommendations
- Escalation severity if applicable
````

---

# AI Drift Detection Prompt

```text
Analyze the following communication samples for behavioral inconsistency.

Identify:
- emotional tone drift
- excessive certainty
- inconsistent escalation behavior
- hidden AI behavior
- promotional bias
- accessibility concerns

Compare outputs against the approved behavioral taxonomy.

Return:
- drift type
- severity level
- operational risk
- remediation guidance
```

---

# Incident Communication Review Prompt

```text
Evaluate this operational incident message.

Review whether the communication:
- explains impact clearly
- maintains calm and trust
- avoids panic escalation
- provides actionable next steps
- preserves transparency
- supports workflow continuity

Return:
- trust stability score
- escalation quality score
- clarity score
- behavioral inconsistencies
- suggested rewrite
```

# Multilingual Tone Evaluation Prompt

```text
Compare the following multilingual communication samples.

Evaluate:

- accessibility stability

Identify:
- localization tone drift

- culturally misleading phrasing

Return:
- multilingual consistency score

- remediation recommendations
```

# AI Disclosure Validation Prompt

```text
Review the following AI-generated communication.

Evaluate whether:
- automation is disclosed clearly
- recommendations avoid misleading certainty
- user agency is preserved
- recovery guidance exists
- trust expectations remain realistic

Return:
- AI transparency score
- trust risk level
- governance violations
- recommended revisions
```

# Prompt Governance Rules

Prompts should:

* prioritize trust stability
* avoid subjective-only evaluation
* support measurable governance
* align with behavioral taxonomy
* support multilingual consistency
* preserve escalation clarity

# Evaluation Severity Framework

| Severity | Description                     |
| -------- | ------------------------------- |
| Low      | minor tone inconsistency        |
| Moderate | workflow clarity risk           |
| High     | trust or escalation instability |
| Critical | enterprise or compliance risk   |
